# 可复跑断言（47 条）

本目录是作品的算法断言脚本，随作品本体一起分发，评委可在离线环境复跑。

## 运行

在**作品本体目录**（含 `index.html` 的这一层）执行：

```bash
node test/t01.test.cjs
```

预期输出：`== 结果：47 / 47 PASS，0 FAIL ==`，退出码 0。运行后会更新本目录的 `result.json` / `lpoints.json`（数值证据）。

## 依赖

仅需 Node.js ≥ 18（本机实测 v26.4.0），无第三方包、无网络。`t01.test.cjs` 通过 `require('../algo.js')` 加载作品的算法内核——与页面运行时使用的是同一份 `algo.js`（可用 `sha256` 对照）。

## 覆盖内容

- 质量比与五点几何（L1–L5 位置与平衡残差 |∇Ω|）
- 雅可比常数与零速度面判据
- Routh 稳定判据（含复特征值、等质量双星失稳）
- 三套预设的时间基准（地月 / 日地 / 等质量）
- RK4 传播、最大漂移与终止条件
- 捕获判定三条判据（含反向验证）
- 默认算例「真天平动 vs 零速度面边界滑动」的方向性验证
- `content.js` 的 i18n 完整性、静态数据表与算法一致性、断言数自洽

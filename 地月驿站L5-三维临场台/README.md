# 地月驿站 L5 · 三维临场台（Lunar Station L5 · 3D Console）

> 这是《地月驿站 L5》的**三维视图**：与二维主作品共用同一份 CR3BP 规则内核与同一条捕获判据，
> 把「平面上的五点与零速度曲线」变成「可进入的空间」：三维零速度面、L1 门洞的高度、
> 三角点的面外振荡、以及垂直偏移如何改写「守不守得住」的判定。
>
> **打开方式**：双击本目录 `index.html`。无需联网、无需服务器、无第三方库（WebGL 由本作品自研渲染层完成）。

---

## 导览（评委模式）

顶栏「▶ 导览」：5 站、约 30 秒自动运镜 + 中英字幕（总览 → 门洞 → 驿站 → 俯视 → 翻面）；点画面、滚轮或 Esc 随时退出，退出后回到默认机位与 z₀=0.05 的默认算例。

## 一、这一版比二维版多出来的三件事（都可复算）

| # | 结论 | 实测数字（默认算例 μ=0.012144） | 复跑 |
|---|---|---|---|
| 1 | **垂直模恒稳定**：在 L4/L5 处 r₁ = r₂ = 1，z″ = −z，面外频率恒为 1，周期 = 2π TU = 一个恒星月，**与 μ 无关** | 实测周期 **27.31 d**（理论 27.3217 d；z₀=1e-3 时误差 1.2e-6 TU，且误差随 z₀² 收敛） | `test/t01-3d.test.cjs` E1–E6 |
| 2 | **零速度面是一张有洞的穹顶**：两处引力漏斗 + L1/L2 门洞；门洞高度随 C 变化，C 越接近 C_L1 越窄，等于 C_L1 时关闭 | 默认 C₀=2.9855 时 L1 门洞净高 **0.5623 D ≈ 21.6 万 km** | `test/t01-3d.test.cjs` D1–D5 |
| 3 | **垂直偏移改写判定**：同一切向初值下，把 z₀ 从 0 调到 0.3，驻留比例跌破 90% 阈值，判定翻面 | 翻面点 **z₀ ≈ 0.19 D**（粗网格定位，界面标 `≈`） | `test/t01-3d.test.cjs` F3–F5 |

> 与二维版的口径差异（不回避）：三维版把**演示位放在 L5**（与作品名一致，站体就在 L5），
> 二维版「布置台」演示的是 **L4** 的镜像算例。L4/L5 是等边三角形上的对称点，稳定性、雅可比常数、
> 垂直频率完全相同；但给定初值下的具体轨迹绕数不同（二维 L4 算例 1.07 圈，三维 L5 算例 1.41 圈）——
> 这不是两个算法在打架，而是**同一个方程的两条不同轨道**。

## 二、操作

| 操作 | 方式 |
|---|---|
| 旋转视角 | 拖拽（鼠标 / 触屏单指）；键盘 ← → ↑ ↓ |
| 缩放 | 滚轮 / 双指捏合；键盘 `+` `-` |
| 复位视角 | 双击画布 / `0` 键 / 面板「复位」 |
| 播放 / 暂停 | 面板「播放」；键盘空格 |
| 场景预设 | 垂直驻留（默认）/ 平面算例 / 越界翻面 / 逃逸 |
| 参数 | 横向偏移、切向初速、垂直偏移、判定半径（拖动即重算） |
| 显示开关 | 零速度面 / 轨迹 / 参考网格 / 惯性系 / 自动旋转 |
| 视角预设 | 斜视 / 俯视 / 侧视 / 驿站特写 / 复位 |
| 中英切换 | 右上角 `EN` / `中文` |

「惯性系」把旋转系按当前时间 t 反向旋转（`Rz(−t)`），于是地球—月球真的绕质心转起来；
「驿站特写」把相机目标从质心移到 L5，看站体与绕站的三维天平动。

## 三、文件与职责（三层，与二维版同构）

```
index.html    页面骨架（脚本顺序：二维内核 → 三维内核 → 渲染层 → 场景 → 界面）
style.css     设计系统（与二维版同一套令牌；响应式 / 焦点可见 / prefers-reduced-motion）
algo.js       二维 CR3BP 内核（与主作品同一份文件，SHA256 一致；三维内核复用它做退化对照）
algo3d.js     ★ 三维规则层：Ω(x,y,z)、三维 RK4、雅可比常数、零速度面高度解、
              L1/L2 门洞高度、三维捕获判定、垂直周期实测、Routh 稳定性（面内）+ 垂直模（面外）
gl3d.js       渲染层：自研 WebGL（矩阵、着色器、球/盒/圆柱/圆环、点精灵、投影到屏幕坐标）
scene3d.js    场景装配：地球/月球、五个平动点、零速度面穹顶、门洞标尺、轨迹、驿站站体、星空
ui3d.js       界面层：状态、控件、双语、指标上屏、回放、键盘与触摸、自动化接口 window.__demo3d
test/         三维内核断言（33 条）与结果 JSON；`node test/t01-3d.test.cjs` 直接复跑
截图/         9 张浏览器实拍（1600×1000，非概念图），由 `_pipeline/shoot3d.py` 生成
```

分层理由与二维版一致：**规则层不碰 DOM，呈现层不产出结论**。界面上的每个判定、每个数字都来自
`algo3d.js`，没有一处是文案写死的。

## 五、边界（写清楚，别当成缺陷）

- **尺寸是展示用的**：地球半径放大到 0.085 D（约真实 5 倍）、月球 0.048 D（约 10 倍），否则在 1 D 的
  画面里看不见；站体与轨迹同理。所有**动力学量**（位置、速度、C、周期）不受影响。
- **步长固定**：dt=0.002 TU、12000 步（24 TU）。近月掠过时（逃逸/撞月算例）雅可比漂移会升到 1e-9~1e-6，
  这是固定步长的正常代价，界面如实显示 `|ΔC|`，不藏。
- **零速度面在图上裁到 z=0.6 D**：真实曲面在地球附近发散到几十 D，三维里必须裁；裁切处的颜色淡出到 0，
  不画假边界。门洞高度按真实解算，不受裁切影响。
- **翻面点用粗网格定位**（dt=0.004、步长 0.02 D 扫描）：界面标 `≈`，精确值请用 `test/` 的二分（F5）。
- **无音频**：与主作品一致，全部表达为视觉与交互。

## 六、设计取向

同一套视觉语言（暗底墨色 + 纸面文字 + 陶土/青铜强调、衬线标题 + 等宽数字），让两个入口看起来是
**同一件作品的两个视图**，而不是两个项目。无障碍按主作品同一条线：键盘全可达、焦点可见、
`aria-live` 播报判定、`prefers-reduced-motion` 下关闭自动旋转与过渡、滑块有 `aria-valuetext`。

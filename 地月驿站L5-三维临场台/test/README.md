# 可复跑断言 · 三维内核（33 条）

本目录是《地月驿站 L5 · 三维临场台》的算法断言脚本，随作品本体一起分发，评委可在离线环境复跑。

## 运行

在**作品本体目录**（含 `index.html` 的这一层）执行：

```bash
node test/t01-3d.test.cjs
```

预期：`== 结果：33 PASS / 0 FAIL（共 33 条）==`，退出码 0。运行后会更新本目录的 `result3d.json`（逐条结果与关键数值）。

## 依赖

仅需 Node.js ≥ 18（本机实测 v26.4.0），无第三方包、无网络。
`t01-3d.test.cjs` 通过 `require('../algo.js')` 与 `require('../algo3d.js')` 加载**页面运行时使用的同一份内核**——
二维内核与主作品目录中的 `algo.js` 逐字节一致（SHA256 相同），三维内核只在它基础上加 z 方向。

## 覆盖内容

| 组 | 内容 |
|---|---|
| A | 三维 → 二维退化一致性（势、运动方程、2000 步轨迹、雅可比常数） |
| B | 五个平动点在三维里的平衡残差；L4/L5 的 r₁ = r₂ = 1；z 方向扰动必然不平衡（反向） |
| C | 雅可比守恒（平面 / 带面外运动），以及「同一条轨道换欧拉积分漂移升高 3 个数量级」的反向验证 |
| D | 零速度面高度解满足 v²=0、随 C 单调、不可达点返回 null、L1/L2 门洞高度与关闭条件 |
| E | 三角点垂直模周期 = 2π TU（L4、L5、日地系统三处），振幅守恒，误差随 z₀² 收敛 |
| F | 三维捕获判定与二维判定在 z₀=0 时完全一致；垂直偏移改写判定；翻转点落在 [0.13,0.17]；非法目标点报错；逃逸算例 |
| G | 非有限状态终止、撞星判定、9900 格穹顶计算耗时 < 120 ms、C₀ 低于 C_L4 的方向性 |

## 为什么这些断言值得信

- **每一条都有反向对照**：不是只验「对的能过」，还验「错的必须失败」（坏积分器漂移必须变大、
  L4 沿 z 平移后残差必须 >1e-4、不可达点必须返回 null、目标点写错必须抛错）。
- **数值不是自证**：垂直周期与门洞高度都有独立的解析/几何对照（2π TU、2·|z|(C)），
  实测值只做核对，不做循环论证。
- **可复算**：断言只用 `algo.js` / `algo3d.js`，不碰 DOM、不依赖随机数（唯一随机处用固定种子的 mulberry）。
